# Example data

The example spectra distributed with SpectraPyle are a subset of 100
Euclid NISP spectra from the public Euclid Quick Data Release 1 (Q1).

These data are included solely as example data for demonstrating and
testing SpectraPyle and are not covered by the MIT License applying to
the SpectraPyle software.

For information on the Euclid Q1 data release, data products, and
applicable data policies, please refer to the official Euclid/ESA
documentation.
